# CSS Practice Assignments

A simple project containing HTML and CSS practice exercises, including backgrounds, Flexbox, Grid, animations, and responsive layouts.

## Files
* `index.html`
* `main.css`

## Install the Project on Your Desktop

Since the GitHub repository already exists, clone it directly to your Desktop.

### 1. Open Terminal

Go to your Desktop:

```bash
cd ~/Desktop
```

### 2. Clone the Repository

Replace `<your-username>` and `<repo-name>` with your GitHub username and repository name:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
```

### 3. Open the Project

Move into the project folder:

```bash
cd <repo-name>
```

If you use VS Code:

```bash
code .
```

### 4. Run the Project

Open `index.html` in your browser.

You can either:

* Double-click `index.html`
* Or right-click `index.html` and choose **Open with Browser**

No installation or additional dependencies are required.

## Updating the Project

If the repository is already cloned and you want to get the latest changes from GitHub:

```bash
cd <repo-name>
git pull
```
